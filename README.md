# ЛБ1 Лінійні та розгалужені алгоритми
- **Дисципліна:** Основи програмування
- **Група:** ІІТ-26-1
- **Варіант:** Варіант 1. Підсумковий результат за трьома компонентами
- **Мова/стандарт:** C++ (ISO C++)

## Призначення
Програма розраховує підсумковий бал за трьома складниками (quiz, practice, exam) та класифікує результат за категоріями.

## Вхідні дані та правила
- quiz (0–20 балів)
- practice (0–30 балів)
- exam (0–50 балів)
- Формула: total = quiz + practice + exam
- Рівні: <50 (доопрацювання), 50–69 (базовий), 70–84 (добрий), 85–100 (високий).
