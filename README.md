## Опис завдання
Програма послідовно читає N записів (бали за тест, практику та іспит) і обчислює показник за формулою:
`m = quiz + practice + exam`

**Межі полів:**
- quiz: 0-20
- practice: 0-30
- exam: 0-50

**Правила класифікації:**
- m < 50: "потрібне доопрацювання"
- m <= 69: "базовий рівень"
- m <= 84: "добрий рівень"
- m >= 85: "високий рівень"

**Умова пошуку:** m >= 50.

## Збірка та запуск
Програма скомпільована за допомогою MinGW (g++).
Команда для збірки: `g++ -std=c++17 -g lab2.cpp -o lab2.exe`
